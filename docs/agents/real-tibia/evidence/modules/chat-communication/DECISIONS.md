# Chat Communication evidence decisions

## Selected decision

Record one bounded current-Canary source claim covering channel definition loading, callback binding, user membership and private-channel lifecycle.

## Evidence and constraints

The selected registry and `chat.hpp`/`chat.cpp` blobs are exact. No data, protocol, client, runtime capture or official-behavior source is selected.

## Rejected alternatives

- Treat channel data or Lua callback contents as proven without selecting them.
- Infer packet delivery, privacy, moderation or client compatibility from send-method calls.
- Treat party/guild channel maps as proof of party or guild membership authorization.
- Create a broad owner request before a specific missing proof question is isolated.
